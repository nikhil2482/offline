# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on the Security tab of this repository. Do not open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. You will get a reply within 7 days.

## Scope

This project handles public data only. Never load private or sensitive data into it, even for testing.

## Supported versions

Only the latest commit on `main` receives fixes.
